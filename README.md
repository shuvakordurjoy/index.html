# Shuvakor Bhowmik Durjoy — Official Portfolio Website

This repository contains the complete, mobile-responsive portfolio website for **Shuvakor Bhowmik Durjoy** (*B.Sc. in Textile Engineering — Wet Processing, BGMEA University of Fashion & Technology*), designed in the editorial luxury style of Perplexity Comet.

## Included Files

- `index.html` — Main SEO-optimized portfolio page with JSON-LD `Person` schema for Google Search indexing, interactive Career Assistant, KDS Textile Mills QC showcase, Ozone vs. Acid Wash research comparator, and FAQ accordion.
- `styles.css` — Custom stylesheet featuring editorial serif typography, 3D planetary spheres, cosmic nebula cards, and smooth animations.
- `script.js` — Interactive logic for English/Bengali language switching, live QC simulation, workflow stage explorer, and direct email/WhatsApp outreach composer.
- `assets/profile.jpg` — Official portrait photo extracted from the CV.
- `assets/signature.png` — Authenticated signature extracted from the CV.
- `assets/Shuvakor_Bhowmik_Durjoy_CV.pdf` — Official 2-page PDF Curriculum Vitae wired to the **Download Official CV** buttons.
- `.nojekyll` & `robots.txt` — Configuration files for instant GitHub Pages deployment and Google Search Console crawling.

## How to Publish Free on GitHub Pages & Google

1. **Create a GitHub Repository**:
   - Sign in to [GitHub](https://github.com/) and click **New repository**.
   - Name the repository `<your-github-username>.github.io` (or `portfolio`).
   - Set visibility to **Public** and click **Create repository**.
2. **Upload These Files**:
   - Unzip `shuvakor-durjoy-portfolio-github.zip`.
   - Click **Add file → Upload files** in your GitHub repository.
   - Drag and drop all files and the `assets/` folder (`index.html`, `styles.css`, `script.js`, `.nojekyll`, `robots.txt`, `README.md`, and `assets/`).
   - Click **Commit changes**.
3. **Activate GitHub Pages**:
   - Go to your repository **Settings → Pages** (on the left sidebar).
   - Under **Build and deployment → Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
   - Within 1–2 minutes, your live website URL will appear at `https://<your-github-username>.github.io/`.
4. **Make It Appear on Google Search**:
   - Open [Google Search Console](https://search.google.com/search-console).
   - Enter your GitHub Pages URL under **URL Prefix** and request indexing for your homepage. The built-in JSON-LD `Person` schema and meta tags in `index.html` are pre-configured for Google Search.
